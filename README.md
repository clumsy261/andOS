# andOS
Custom webOS with a lot of potential.

![Os desktop image](desktop.png)

The current version is hosted right here:
https://clumsy261.github.io/andOS/

Features include:
-home greeting
-weather service
-clock/calendar

All services are currently only available for the user's ip location, will make them modular later.

The apps use a template, custom built to be imported into the main script.js later. An example template is the actual home.js app, used for the initial greeting.
